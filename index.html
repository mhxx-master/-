# 利用した公開解析

このプロジェクトは apmnnn 氏が MIT ライセンスで公開する
[MHXX乱数解析ツール mhxx-rng](https://github.com/apmnnn/mhxx-rng)
のXorshift128乱数式、スキル抽選表、スロット表とジャンプ多項式を JavaScript に移植しています。原作者の独立した解析に基づいています。

元コードは特定コミット `b882bae8412a0311c84e5c5363a344c85599cf40` に固定しており、
原作者の公開コードの計算式・テーブルを移植した JavaScript コード（`rng.js`）をこのZIPに含みます。
